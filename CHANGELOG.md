# Changelog

## 0.2.1

- Knows the whole family: PR7-DU, PR7-CB, PR7-IS, PR7-PM and PR7-SM are in its list of family apps (their permanent install IDs), so the family links find them when they're installed.

## 0.2.0

- **Check for Updates knows PR7-U**, the family installer. When it's installed, the update window has **Update All in PR7-U**, and a check by hand that finds PR7-P up to date offers to open PR7-U for the rest of the family.

## 0.1.0

- First version: an image viewer that works the way IrfanView and ImageGlass work, in the Paragon family look.
- Reads JPEG, PNG, animated GIF, WebP, BMP, TIFF, ICO, SVG, TGA, AVIF, JPEG 2000, PCX and Photoshop files; the
  camera's orientation is applied.
- Moves through the folder (keys, wheel, thumbnail strip); fit only big images, fit to window, original size, zoom at
  the pointer; selection and moving the picture with the mouse.
- Rotate, flip, crop, resize, canvas size, auto-adjust, sharpen, colour corrections, greyscale, negative, with Undo.
- Save and Save as in JPEG (camera details kept, orientation reset), PNG, WebP, BMP, TIFF, GIF and AVIF.
- Copy to, Move to, Rename, Delete to the Recycle Bin, Show in folder, Set as wallpaper, Print.
- Image information with the camera details, Thumbnails, Slideshow, full screen.
- One window for every picture opened; Open with and Default apps; Check for updates; OBSIDIAN and AURORA.
